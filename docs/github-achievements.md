## 怎样判断拿到了

GitHub 官方没有公布完整解锁规则，详情面板会展示说明和相关事件。因此下表把官方产品详情与社区观察分开，授予状态以个人主页实际展示为准。GitHub 自 2026-09-11 起在主页展示已获得的最高档位。铜牌 x2、银牌 x3、金牌 x4 是等级标签，例如 Pull Shark x2 对应常见的 16 次合并门槛。[官方成就介绍](https://github.blog/news-insights/product-news/introducing-achievements-recognizing-the-many-stages-of-a-developers-coding-journey/) · [最高档位显示更新](https://github.blog/changelog/2026-09-11-profiles-now-show-your-highest-achievement-badge-tier/)

单项成就可以隐藏，全部成就也能关闭展示。公开主页未显示的项目只能记为“未公开显示”。[官方可见性说明](https://github.blog/changelog/2022-10-07-visibility-settings-for-individual-achievements/)

## 本轮落实方式

将本指南加入个人主页仓库，并给 README 增加入口。内容核对后创建一个真实维护 issue，通过对应文档 PR 的 Closes 引用完成需求，再按该仓库允许的正常流程合并。

这一个真实维护交付可形成 Quickdraw、YOLO 的候选触发事件。是否获得须在合并后再次查看公开主页与详情，GitHub 的处理延迟与未公开规则会影响结果。
